## 🌱 Alustamine

See kursus sisaldab õppetunde, mis käsitlevad AI-agentide loomise ja juurutamise aluseid.

Iga õppetund tugineb eelnevale, seega soovitame alustada algusest ja liikuda lõpuni.

Kui soovite rohkem uurida AI-agentidega seotud teemasid, võite vaadata [AI-agentide algajate kursust](https://aka.ms/ai-agents-beginners).

### Tutvuge teiste õppijatega, saage vastused oma küsimustele

Kui jääte jänni või teil on küsimusi AI-agentide loomise kohta, liituge meie pühendatud Discordi kanaliga [Microsoft Foundry Discordis](https://discord.gg/Kuaw3ktsu6).

### Mida vajate

Igal õppetunnil on oma koodinäide, mida saate lokaalsetes tingimustes käivitada. Võite [forkida selle hoidla](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork), et luua oma koopia.

See kursus kasutab praegu järgnevat:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — projekt, kus on juurutatud **GPT-5 seeria** mudel (näiteks `gpt-5.1`). Ärge kasutage pensionile jäänud GPT-4o / GPT-4.1 mudeleid.
- [Azure OpenAI teenus](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — logige enne näidiskoodi käivitamist sisse `az login` käsuga
- **Python 3.12 või uuem versioon**

Palun veenduge, et teil on nendele teenustele ligipääs enne alustamist.

> **💰 Kulud ja puhastamine.** Praktilised õppetunnid loovad reaalseid Azure ressursse — Microsoft Foundry
> projekt, mudeli juurutuse, vektorpoodi ja (õppetundides 4–6) majutatud agendid ning tööriistakastid.
> Need võivad olemas olles kulusid tekitada. Kui õppetund või kursus on läbi, kustutage
> vajalikud ressursid. Kõige lihtsam on panna kõik pühendatud ressursirühma
> ja kustutada kogu rühm pärast lõpetamist:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Samuti võite kustutada üksikuid agente, vektorpoodesid ja tööriistakaste Foundry portaali kaudu.

> **Märkus mudelite kohta.** See kursus kasutab kõigi mudelite jaoks **Microsoft Foundry** teenust. See ei kasuta
> *GitHubi mudeleid*, mis on pensionile suunatud alates **30. juulist 2026** — Microsoft Foundry on
> ametlik migratsioonitee. Kui teil on vanemat koodi, mis kasutab GitHubi mudeleid, suunake see
> Foundry mudeli juurutusele.

Peagi lisanduvad täiendavad võimalused mudelite majutamiseks ja teenustele.

| [Agendi arendus](./lesson-2-agent-development/README.md)  | Microsoft Agent Frameworki (MAF) kasutades looge spetsialiseeritud agente uute arendajate toetamiseks.       |
