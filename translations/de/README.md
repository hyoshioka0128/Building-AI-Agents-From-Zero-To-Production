## 🌱 Erste Schritte

Dieser Kurs enthält Lektionen, die die Grundlagen des Aufbaus und der Bereitstellung von KI-Agenten behandeln.

Jede Lektion baut auf der vorherigen auf, weshalb wir empfehlen, von Anfang an zu beginnen und sich bis zum Ende durchzuarbeiten.

Wenn Sie mehr zu KI-Agenten-Themen erkunden möchten, können Sie sich den [Kurs für Einsteiger zu KI-Agenten](https://aka.ms/ai-agents-beginners) ansehen.

### Lernen Sie andere Lernende kennen, erhalten Sie Antworten auf Ihre Fragen

Wenn Sie nicht weiterkommen oder Fragen zum Aufbau von KI-Agenten haben, treten Sie unserem dedizierten Discord-Kanal im [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6) bei.

### Was Sie benötigen

Jede Lektion enthält ein eigenes Codebeispiel, das Sie lokal ausführen können. Sie können dieses Repository [forken](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork), um Ihre eigene Kopie zu erstellen.

Dieser Kurs verwendet derzeit Folgendes:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — ein Projekt mit einem bereitgestellten **GPT-5-Serie** Modell (zum Beispiel `gpt-5.1`). Verwenden Sie **nicht** die eingestellten GPT-4o / GPT-4.1 Modelle.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — Melden Sie sich mit `az login` an, bevor Sie ein Beispiel ausführen.
- **Python 3.12 oder neuer**

Bitte stellen Sie sicher, dass Sie Zugang zu diesen Diensten haben, bevor Sie beginnen.

> **💰 Kosten & Bereinigung.** Die praktischen Lektionen erstellen echte Azure-Ressourcen — ein Microsoft Foundry
> Projekt, eine Modellbereitstellung, einen Vektorspeicher und (in Lektionen 4–6) gehostete Agenten und Werkzeugkästen.
> Diese können Kosten verursachen, solange sie existieren. Wenn Sie eine Lektion oder den Kurs beenden, löschen Sie
> die Ressourcen, die Sie nicht mehr benötigen. Der einfachste Weg ist, alles in einer dedizierten Ressourcengruppe zu bündeln
> und die gesamte Gruppe zu löschen, wenn Sie fertig sind:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Sie können auch einzelne Agenten, Vektorspeicher und Werkzeugkästen über das Foundry-Portal löschen.

> **Hinweis zu Modellen.** Dieser Kurs stellt alle Modelle über **Microsoft Foundry** bereit. Er verwendet **nicht**
> *GitHub-Modelle*, die am **30. Juli 2026** eingestellt werden — Microsoft Foundry ist der
> offizielle Migrationspfad. Wenn Sie älteren Code haben, der GitHub-Modelle anspricht, richten Sie ihn stattdessen auf eine Foundry
> Modellbereitstellung.

Weitere Optionen zur Modell-Hosting und Diensten folgen in Kürze.

## 🗃️ Lektionen

| **Lektion**         | **Beschreibung**                                                                                  |
|--------------------|--------------------------------------------------------------------------------------------------|
| [Agentendesign](./lesson-1-agent-design/README.md)       | Eine Einführung in unseren Anwendungsfall "Developer Onboarding" und wie man effektive Agenten entwirft  |
| [Agentenentwicklung](./lesson-2-agent-development/README.md)  | Mit dem Microsoft Agent Framework (MAF) eine Reihe spezialisierter Agenten erstellen, um neuen Entwicklern den Einstieg zu erleichtern.       |
| [Agentenbewertungen](./lesson-3-agent-evals/README.md)  | Verwenden Sie Microsoft Foundry, um herauszufinden, wie gut unsere KI-Agenten funktionieren und wie man sie verbessert. |
| [Agentenbereitstellung](./lesson-4-agentdeployment/README.md)   | Verwenden Sie Microsoft Foundry gehostete Agenten und OpenAI ChatKit, um einen KI-Agenten in Produktion zu bringen.       |
| [Produktion gehostete Agenten](./lesson-5-hosted-agents-production/README.md)   | Bringen Sie einen gehosteten Agenten in die Unternehmensproduktion: Gehostete Agenten vs. Fähigkeit Hosts, eigenes Speicher-, Speicher- und Governance-Modell.       |
| [Microsoft Werkzeugkasten](./lesson-6-toolbox/README.md)   | Werkzeuge einmal definieren und zentral verwalten: bauen Sie einen Werkzeugkasten, verwenden Sie ihn von einem Agenten über einen MCP-Endpunkt und versionieren Sie Werkzeuge sicher.       |
| [Multi-Agent & A2A](./lesson-7-multi-agent-a2a/README.md)   | Komponieren Sie Agenten als vernetzte Dienste: setzen Sie einen Agenten über das offene Agent-zu-Agent (A2A)-Protokoll ein und nutzen Sie einen entfernten Agenten als Peer.       |
