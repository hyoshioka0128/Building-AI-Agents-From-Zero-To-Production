## [Модернизация Foundry 2026]

Полное обновление технической части, терминологии и учебной программы в соответствии с платформой
**Microsoft Foundry 2026**. См. `MIGRATION-GUIDE.md` для деталей миграции на уровне кода.

### Добавлено
- **Урок 5 – Продакшн-хостинг агентов** (`lesson-5-hosted-agents-production/`): хостинг агентов против
  Capability Hosts, использование собственного Cosmos DB / Storage / AI Search, управление памятью и сохранением потоков,
  рабочие процессы одобрения хостинга MCP и чеклист по управлению.
- **Урок 6 – Microsoft Toolbox** (`lesson-6-toolbox/`): определение инструментов единожды и их централизованное управление,
  плюс runnable пример использования (`toolbox_agent.py`), который обращается к Toolbox через
  единственную точку входа MCP.
- **Урок 7 – Мульти-Агент & A2A** (`lesson-7-multi-agent-a2a/`): открытие агента через открытый
  протокол Агент-К-Агенту (A2A) (`a2a_server.py`) и использование удалённого агента как равного
  (`a2a_client.py`). Валидировано «живое» сквозное тестирование.
- **Агент по рекомендации задач** (`lesson-2-agent-development/task-recommendation-agent.py`):
  реализует Сценарий 2 из Урока 1, используя удаленный сервер MCP GitHub как инструмент.
- **Скрипт настройки векторного хранилища** (`setup_vector_store.py`): создает и наполняет векторное хранилище,
  от которого зависит агент по поиску сотрудников (ранее упоминался, но отсутствовал).
- **CI smoketest + статическая проверка** (`.github/workflows/smoke-test-hosted-agent.yml`): `static` задачa запускает
  `py_compile` и markdown-link-check на каждом PR/пуше; `smoke` задача запускает AI Smoke Test
  действие против развернутого хостинг-агента (OIDC, `workflow_dispatch`).
- Добавлены инструкции по требованиям и настройке для каждого урока и в корневом README
  (Python 3.12+, `az login`, рекомендации по моделям, стоимость и очистка).
- Новый основной документ: `MIGRATION-GUIDE.md`.

### Изменено
- **Ребрендинг**: *Azure AI Foundry* → **Microsoft Foundry** по всему курсу.
- **Миграция SDK** на текущую версию Microsoft Agent Framework — примеры теперь используют
  `agent-framework` `1.2.0` с `FoundryChatClient` и **Responses API**, заменяющим
  прежние паттерны `AzureAIClient` / `AzureAIAgentClient` / `AzureOpenAIChatClient`.
- **Закрепленные зависимости**: `requirements.txt` теперь указывает конкретные версии `agent-framework`, `agent-framework-foundry`
  и связанных пакетов вместо установки непроверенных pre-release, что делает примеры воспроизводимыми.
- **Переменные окружения** выравнены в `deploy.py`, `agent.yaml`, `main.py` и
  `.env.example` файлах.
- Архитектурные диаграммы в README и каталог агентов/сценариев переписаны для соответствия поставляемому коду.

### Исправлено
- Исправлена поломанная ссылка в корневом README на Урок 4 (`lesson-4-agentdeployment`).
- Создано содержимое ранее пустого README для Урока 3 (оценки + наблюдаемость).
- Заменён устаревший паттерн `asyncio.get_event_loop().run_until_complete` в
  агенте по рекомендации обучения.

### Устарело / удалено
- Удалено всё использование устаревших моделей **GPT-4o / GPT-4.1**. Примеры чата и оценки теперь используют
  **gpt-5.1**; примеры кодирования — **gpt-5-codex**.
- Задокументировано, что **GitHub Models** снимаются с поддержки (30 июля 2026 года); курс обслуживает все модели
  через Microsoft Foundry и не зависит от GitHub Models.
