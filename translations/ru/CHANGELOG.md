# Журнал изменений

Все заметные изменения в **Building AI Agents from Zero to Production** задокументированы здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Этот курс — это живой учебный план, а не версия программного пакета, поэтому записи сгруппированы
по дате внесения изменений, а не по семантическому номеру версии.

## [Не выпущено]

### Добавлено
- **Гигиена репозитория для публичного распространения** — усилен `.gitignore` с отдельным разделом для
  Python / ноутбуков / секретов / ОС (варианты env-файлов, `.pytest_cache/`, `.mypy_cache/`,

  и файлы навыков курса.

### Изменено
- Подготовлен репозиторий для публичного распространения: из опубликованных документов удалены персональные
  и живые идентификаторы окружения (аккаунт, проект, группа ресурсов и имена идентификаций),
  а внутренний отчёт по модернизации/анализу пробелов вынесен из репозитория (его резюме для обучающихся
  находится в этом журнале изменений).

## [Модернизация Foundry 2026]

Полное техническое, терминологическое и учебное обновление, выравнивающее курс с платформой
**Microsoft Foundry 2026**. Подробности по миграции кода смотрите в `MIGRATION-GUIDE.md`.

### Добавлено
- **Урок 5 – Развернутые агенты в продакшене** (`lesson-5-hosted-agents-production/`): Развернутые агенты vs
  Capability Hosts, возможность использовать собственные Cosmos DB / Storage / AI Search, сохранение памяти
  и потоков, процедуры одобрения Hosted MCP и чеклист управления.
- **Урок 6 – Microsoft Toolbox** (`lesson-6-toolbox/`): определение инструментов один раз и централизованное
  управление ими, плюс пример запуска (`toolbox_agent.py`), который обращается к набору инструментов
  через единый MCP endpoint.
- **Урок 7 – Мультиагент и A2A** (`lesson-7-multi-agent-a2a/`): открытие агента по открытому протоколу
  Agent-to-Agent (A2A) (`a2a_server.py`) и использование удалённого агента в качестве пира
  (`a2a_client.py`). Протестировано вживую сквозным способом.
- **Агент рекомендаций задач** (`lesson-2-agent-development/task-recommendation-agent.py`):
  реализует Сценарий 2 Урока 1 с использованием GitHub удалённого MCP сервера как инструмента.
- **Скрипт настройки векторного хранилища** (`setup_vector_store.py`): создаёт и заполняет векторное хранилище,
  от которого зависит агент поиска сотрудников (ранее упоминался, но отсутствовал).
- **CI smoke + статический gate** (`.github/workflows/smoke-test-hosted-agent.yml`): работа `static`
  выполняет `py_compile` и markdown-link-check на каждом PR/push; работа `smoke` запускает AI Smoke Test
  действие против развернутого агента (OIDC, `workflow_dispatch`).
- Добавлены **предварительные требования и руководство по настройке** в каждый урок и в корневой README
  (Python 3.12+, `az login`, рекомендации по моделям, стоимость и очистка).
- **Новый флагманский документ**: `MIGRATION-GUIDE.md`.

### Изменено
- **Ребрендинг**: *Azure AI Foundry* → **Microsoft Foundry** по всему курсу.
- **Миграция SDK** на текущий API Microsoft Agent Framework — примеры теперь используют
  `agent-framework` `1.2.0` с `FoundryChatClient` и **Responses API**, заменяющим
  прежние паттерны `AzureAIClient` / `AzureAIAgentClient` / `AzureOpenAIChatClient`.
- **Зафиксированные зависимости**: в `requirements.txt` теперь фиксируются `agent-framework`, `agent-framework-foundry`
  и связанные пакеты вместо установки незакрепленных pre-release, что делает примеры воспроизводимыми.
- **Переменные окружения** унифицированы в `deploy.py`, `agent.yaml`, `main.py` и
  `.env.example`.
- Диаграммы архитектуры в README и каталог агентов/сценариев переписаны в соответствии с доставленным кодом.

### Исправлено
- Исправлена сломанная ссылка в корневом README на Урок 4 (`lesson-4-agentdeployment`).
- Написан ранее пустой README для Урока 3 (оценки + наблюдаемость).
- Заменён устаревший паттерн `asyncio.get_event_loop().run_until_complete` в
  агенте рекомендаций по обучению.

### Устаревшее / удалено
- Удалено все использование устаревших моделей **GPT-4o / GPT-4.1**. Примеры чата и оценки теперь используют
  **gpt-5.1**; примеры программирования — **gpt-5-codex**.
- Задокументировано, что **GitHub Models** выводится из эксплуатации (30 июля 2026 года); курс обслуживает все модели
  через Microsoft Foundry и не зависит от GitHub Models.
