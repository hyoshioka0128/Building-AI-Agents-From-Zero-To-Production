## 🌱 آغاز کریں

یہ کورس AI ایجنٹس کی تعمیر اور تعیناتی کے بنیادی اصولوں کو کور کرتا ہے۔

ہر سبق پچھلے سبق پر مبنی ہوتا ہے، لہٰذا ہم تجویز کرتے ہیں کہ شروع سے شروع کریں اور آخر تک کام کریں۔

اگر آپ AI ایجنٹ کے موضوعات میں مزید تفصیل میں جانا چاہتے ہیں، تو آپ [AI Agents For Beginners کورس](https://aka.ms/ai-agents-beginners) دیکھ سکتے ہیں۔

### دوسرے سیکھنے والوں سے ملاقات کریں، اپنے سوالات کے جوابات حاصل کریں

اگر آپ پھنس جائیں یا AI ایجنٹس کی تعمیر کے بارے میں کوئی سوال ہو تو ہمارے مخصوص Discord چینل میں شامل ہوں [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6)۔

### آپ کو کیا چاہیے


ہر سبق کا اپنا ایک کوڈ سیمپل ہوتا ہے جسے آپ مقامی طور پر چلا سکتے ہیں۔ آپ [اس ریپو کو فورک کر سکتے ہیں](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) تاکہ اپنی کاپی بنا سکیں۔

یہ کورس فی الحال درج ذیل استعمال کرتا ہے:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — ایک پروجیکٹ جس میں ایک تعینات **GPT-5 سیریز** ماڈل ہے (مثال کے طور پر `gpt-5.1`)۔ پرانے GPT-4o / GPT-4.1 ماڈلز کا استعمال **نہیں** کریں۔
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — کوئی بھی سیمپل چلانے سے پہلے `az login` کے ساتھ سائن ان کریں
- **Python 3.12 یا اس کے بعد کا ورژن**

براہ کرم شروع کرنے سے پہلے یقینی بنائیں کہ آپ کو ان خدمات تک رسائی حاصل ہے۔

> **💰 لاگت اور صفائی۔** عملی اسباق حقیقی Azure وسائل بناتے ہیں — ایک Microsoft Foundry
> پروجیکٹ، ایک ماڈل کی تعیناتی، ایک ویکٹر اسٹور، اور (سبق 4–6 میں) میزبانی شدہ ایجنٹس اور ٹول بکس۔
> یہ وسائل موجود رہنے کے دوران لاگت لگا سکتے ہیں۔ جب آپ سبق مکمل کر لیں — یا پورا کورس — تو
> ایسے وسائل کو حذف کر دیں جن کی آپ کو ضرورت نہیں ہے۔ آسان طریقہ یہ ہے کہ سب کچھ ایک مخصوص وسائل
> گروپ میں رکھیں اور جب کام ختم ہو جائے تو پورے گروپ کو حذف کر دیں:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> آپ Foundry پورٹل سے انفرادی ایجنٹس، ویکٹر اسٹورز، اور ٹول بکس بھی حذف کر سکتے ہیں۔

> **ماڈلز پر نوٹ۔** یہ کورس تمام ماڈلز کو **Microsoft Foundry** کے ذریعے فراہم کرتا ہے۔ یہ **GitHub Models** استعمال نہیں کرتا،
> جو کہ **30 جولائی، 2026** کو بند ہو رہے ہیں — Microsoft Foundry باضابطہ منتقلی کا راستہ ہے۔ اگر آپ کے پاس پرانا کوڈ ہے
> جو GitHub Models کو کال کرتا ہے، تو اسے Foundry ماڈل کی تعیناتی کی طرف موڑ دیں۔

ٹریڈ مارکس یا لوگوز کے مجاز استعمال کے لیے
[Microsoft's Trademark & Brand Guidelines](https://www.microsoft.com/legal/intellectualproperty/trademarks/usage/general) کی پیروی اور پابندی ضروری ہے۔
اس پروجیکٹ کے ترمیم شدہ ورژنز میں مائیکروسافٹ کے ٹریڈ مارکس یا لوگوز کا استعمال الجھن پیدا نہیں کرنا چاہیے اور نہ ہی مائیکروسافٹ کی معاونت کا تاثر دینا چاہیے۔
تیسرے فریق کے ٹریڈ مارکس یا لوگوز کے کسی بھی استعمال کے لیے ان تیسرے فریق کی پالیسیاں لاگو ہوتی ہیں۔
