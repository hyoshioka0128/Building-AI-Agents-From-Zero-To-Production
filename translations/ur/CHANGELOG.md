# تبدیلیوں کی فہرست

**Building AI Agents from Zero to Production** میں کی گئی تمام نمایاں تبدیلیاں یہاں دستاویز کی گئی ہیں۔

اس کا فارمیٹ [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) پر مبنی ہے۔
یہ کورس ایک زندہ نصاب ہے، نہ کہ ورژن شدہ سافٹ ویئر پیکیج، لہٰذا اندراجات کو تبدیلیوں کی تاریخ کے حساب سے گروپ کیا جاتا ہے
بجائے ایک معنوی ورژن نمبر کے۔

## [غیر جاری کردہ]

### شامل
- **عوامی اشتراک کے لیے ذخیرہ کی صفائی** — `.gitignore` کو سخت بنایا گیا ہے جس میں مخصوص
  Python / نوٹ بکس / راز / OS سیکشن (env-file متغیرات، `.pytest_cache/`, `.mypy_cache/`,
  `.ruff_cache/`, `.ipynb_checkpoints/`, `*.egg-info/`)، جبکہ ہر `*.env.example` کو ٹریک کیا گیا ہے۔
  یہ `CHANGELOG.md`, `AGENTS.md` کنٹری بیوٹر / ایجنٹ گائیڈ، اور کورس اسکل فائلیں شامل کی گئی ہیں۔


### تبدیل شدہ
- عوامی اشتراک کے لیے ذخیرہ کی تیاری: شائع شدہ دستاویزات سے ذاتی اور زندہ ماحول کے شناخت کنندگان کو صاف کیا گیا
  (اکاؤنٹ، پراجیکٹ، ریسورس-گروپ اور شناخت کے نام) اور اندرونی
  جدید کاری / فرق تجزیہ کی رپورٹ کو ذخیرہ سے ہٹا دیا گیا (اس کا لرنر-مخاطب خلاصہ اس
  تبدیلی فہرست میں موجود ہے)۔

## [2026 فاؤنڈری جدید کاری]

ایک مکمل تکنیکی، اصطلاحات اور نصاب کی تجدید جو کورس کو
**Microsoft Foundry 2026** پلیٹ فارم کے مطابق بناتی ہے۔ کوڈ کی سطح کی منتقلی کی تفصیلات کے لیے `MIGRATION-GUIDE.md` دیکھیں۔

### شامل
- **سبق 5 – پروڈکشن پر میزبان ایجنٹس** (`lesson-5-hosted-agents-production/`): میزبان ایجنٹس بمقابلہ
  کیپبلیٹی ہوسٹس، اپنا Cosmos DB / اسٹوریج / AI سرچ لائیں، یادداشت اور تھریڈ مستقل مزاجی،
  میزبان MCP منظوری کے ورک فلو، اور گورننس چیک لسٹ۔
- **سبق 6 – Microsoft Toolbox** (`lesson-6-toolbox/`): ٹولز کو ایک بار تعریف کریں اور انہیں
  مرکزی طور پر گورن کریں، نیز ایک چلانے والا نمونہ (`toolbox_agent.py`) جو ایک ٹول باکس تک
  ایک MCP اینڈپوائنٹ کے ذریعے رسائی حاصل کرتا ہے۔
- **سبق 7 – ملٹی ایجنٹ اور A2A** (`lesson-7-multi-agent-a2a/`): ایک ایجنٹ کو کھلے پر سامنے لائیں
  ایجنٹ ٹو ایجنٹ (A2A) پروٹوکول (`a2a_server.py`) کے ذریعے اور ایک دور دراز ایجنٹ کو بطور ساتھی استعمال کریں
  (`a2a_client.py`)۔ براہ راست ایند سے ایند تک تصدیق شدہ۔
- **ٹاسک ریکومنڈیشن ایجنٹ** (`lesson-2-agent-development/task-recommendation-agent.py`):
  سبق 1 منظرنامہ 2 کو GitHub ریموٹ MCP سرور کے بطور ٹول استعمال کرتے ہوئے نافذ کرتا ہے۔
- **وییکٹر سٹور سیٹ اپ اسکرپٹ** (`setup_vector_store.py`): وہ وییکٹر سٹور بناتا اور بھر دیتا ہے
  جس پر ملازم-تلاش ایجنٹ منحصر ہے (پہلے حوالہ دیا گیا لیکن غائب تھا)۔
- **CI سموک + سٹیٹک گیٹ** (`.github/workflows/smoke-test-hosted-agent.yml`): ایک `static` جاب ہر PR/push پر
  `py_compile` اور markdown-link-check چلاتا ہے؛ ایک `smoke` جاب تعینات میزبان ایجنٹ پر AI سموک ٹیسٹ
  ایکشن چلاتا ہے (OIDC، `workflow_dispatch`)۔
- **سبک سبقوں اور روٹ README میں پری ریکوئیزٹس اور سیٹ اپ گائیڈنس** شامل کی گئی
  (Python 3.12+, `az login`, ماڈل گائیڈنس، لاگت اور صفائی)۔
- **نیا فلیگ شپ ڈاک**: `MIGRATION-GUIDE.md`۔

### تبدیل شدہ
- **ری برانڈ**: *Azure AI Foundry* → **Microsoft Foundry** پورے کورس میں۔
- **SDK منتقلی** موجودہ Microsoft Agent Framework سطح پر — نمونے اب استعمال کرتے ہیں
  `agent-framework` `1.2.0` کو `FoundryChatClient` اور **Responses API** کے ساتھ، جو پہلے کے
  `AzureAIClient` / `AzureAIAgentClient` / `AzureOpenAIChatClient` پیٹرنز کی جگہ لیتا ہے۔
- **پِن کی گئی منحصرات**: `requirements.txt` اب `agent-framework`, `agent-framework-foundry`
  اور متعلقہ پیکجز کو پِن کرتا ہے بجائے اس کے کہ ان پِن کی گئی پری ریلیزز انسٹال کرے، جس سے نمونے قابل تکرار ہوتے ہیں۔
- **ماحولیاتی متغیرات** کو `deploy.py`, `agent.yaml`, `main.py` اور
  `.env.example` فائلوں میں ہم آہنگ کیا گیا ہے۔
- README فن تعمیر کے خاکے اور ایجنٹ / منظرنامہ کیٹلاگ کو شپ کیے گئے کوڈ کے مطابق دوبارہ لکھا گیا۔

### درست کیا گیا
- سبق 4 (`lesson-4-agentdeployment`) کے ٹوٹے ہوئے روٹ-README لنک کو درست کیا گیا۔
- پہلے خالی سبق 3 README (تشخیصات + مشاہدہ پذیری) مرتب کی گئی۔
- لرننگ ریکومنڈیشن ایجنٹ میں پرانا `asyncio.get_event_loop().run_until_complete` پیٹرن تبدیل کیا گیا۔


### منسوخ / ہٹایا گیا
- تمام ریٹائرڈ **GPT-4o / GPT-4.1** ماڈلز کا استعمال ہٹا دیا گیا۔ چیٹ اور تشخیصی نمونے اب استعمال کرتے ہیں
  **gpt-5.1**؛ کوڈنگ کے نمونے **gpt-5-codex** استعمال کرتے ہیں۔
- دستاویزی طور پر بتایا گیا ہے کہ **GitHub Models** کو ریٹائر کیا جا رہا ہے (30 جولائی، 2026)؛ یہ کورس تمام ماڈلز
  Microsoft Foundry کے ذریعے فراہم کرتا ہے اور GitHub Models پر منحصر نہیں ہے۔
