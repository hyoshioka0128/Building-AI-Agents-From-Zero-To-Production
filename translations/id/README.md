## 🌱 Memulai

Kursus ini memiliki pelajaran yang mencakup dasar-dasar membangun dan menerapkan Agen AI.

Setiap pelajaran dibangun berdasarkan pelajaran sebelumnya, jadi kami sarankan memulai dari awal dan melanjutkannya hingga selesai.

Jika Anda ingin mengeksplorasi lebih banyak topik tentang Agen AI, Anda dapat melihat [Kursus AI Agents Untuk Pemula](https://aka.ms/ai-agents-beginners).

### Bertemu Pembelajar Lain, Dapatkan Jawaban untuk Pertanyaan Anda

Jika Anda mengalami kesulitan atau memiliki pertanyaan tentang membangun Agen AI, bergabunglah dengan Saluran Discord khusus kami di [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### Apa yang Anda Butuhkan


Setiap Pelajaran memiliki contoh kode sendiri yang dapat Anda jalankan secara lokal. Anda dapat [fork repo ini](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) untuk membuat salinan Anda sendiri.

Kursus ini saat ini menggunakan hal-hal berikut:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — sebuah proyek dengan model **GPT-5 series** yang sudah diterapkan (misalnya `gpt-5.1`). Jangan gunakan model GPT-4o / GPT-4.1 yang sudah tidak digunakan lagi.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — masuk dengan `az login` sebelum menjalankan contoh apa pun
- **Python 3.12 atau lebih baru**

Pastikan Anda memiliki akses ke layanan ini sebelum memulai.

> **💰 Biaya & pembersihan.** Pelajaran praktek ini membuat sumber daya Azure nyata — sebuah proyek Microsoft Foundry,
> sebuah penerapan model, sebuah toko vektor, dan (dalam Pelajaran 4–6) agen dan kotak alat yang dihosting.
> Ini dapat menimbulkan biaya selama masih ada. Saat Anda selesai dengan pelajaran — atau kursus — hapuslah
> sumber daya yang sudah tidak Anda butuhkan. Pendekatan paling sederhana adalah meletakkan semuanya dalam grup sumber daya khusus
> dan hapus seluruh grup saat Anda selesai:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Anda juga dapat menghapus agen individu, toko vektor, dan kotak alat dari portal Foundry.

> **Catatan mengenai model.** Kursus ini menyediakan semua model melalui **Microsoft Foundry**. Kursus ini **tidak**
> menggunakan *GitHub Models*, yang akan dihentikan pada **30 Juli 2026** — Microsoft Foundry adalah
> jalur migrasi resmi. Jika Anda memiliki kode lama yang memanggil GitHub Models, arahkan ke penerapan
> model Foundry sebagai gantinya.

Pilihan lebih lanjut terkait hosting model dan layanan akan segera hadir.

## 🗃️ Pelajaran

| **Pelajaran**         | **Deskripsi**                                                                                  |
|--------------------|--------------------------------------------------------------------------------------------------|
| [Desain Agen](./lesson-1-agent-design/README.md)       | Pengenalan Kasus Penggunaan Agen "Developer Onboarding" dan cara merancang agen yang efektif  |
| [Pengembangan Agen](./lesson-2-agent-development/README.md)  | Menggunakan Microsoft Agent Framework (MAF), membangun serangkaian agen khusus untuk membantu developer baru onboarding.       |
| [Evaluasi Agen](./lesson-3-agent-evals/README.md)  | Menggunakan Microsoft Foundry, mengetahui seberapa baik kinerja AI Agents kami dan cara meningkatkannya. |
| [Penerapan Agen](./lesson-4-agentdeployment/README.md)   | Menggunakan agen yang dihosting Microsoft Foundry dan OpenAI ChatKit, lihat cara menerapkan AI Agent ke produksi.       |
| [Agen Hosted Produksi](./lesson-5-hosted-agents-production/README.md)   | Membawa agen yang dihosting ke produksi perusahaan: Agen Hosted vs Capability Hosts, bawa penyimpanan, memori, dan tata kelola sendiri.       |
| [Kotak Alat Microsoft](./lesson-6-toolbox/README.md)   | Definisikan alat sekali dan kelola secara terpusat: bangun kotak alat, gunakan dari agen melalui satu endpoint MCP, dan versi alat dengan aman.       |
| [Multi-Agen & A2A](./lesson-7-multi-agent-a2a/README.md)   | Menyusun agen sebagai layanan jaringan: buka agen melalui protokol Agent-to-Agent (A2A) terbuka dan gunakan agen jarak jauh sebagai rekan.       |
