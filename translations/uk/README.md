## 🌱 Початок Роботи

Цей курс містить уроки, які охоплюють основи створення та розгортання AI Агентів.

Кожен урок базується на попередньому, тому ми рекомендуємо починати з початку і послідовно проходити курс до кінця.

Якщо ви хочете більше дізнатися про теми, пов’язані з AI Агентами, ви можете переглянути [Курс AI Агентів для Початківців](https://aka.ms/ai-agents-beginners).

### Познайомтеся з іншими учнями, отримуйте відповіді на свої запитання

Якщо ви застрягли або маєте запитання щодо створення AI Агентів, приєднуйтеся до нашого спеціального каналу Discord у [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### Що вам потрібно


Кожен урок має власний зразок коду, який ви можете запускати локально. Ви можете [форкнути цей репозиторій](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork), щоб створити власну копію.

Цей курс наразі використовує наступне:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — проєкт із розгорнутим **GPT-5 серії** моделлю (наприклад, `gpt-5.1`). Не використовуйте застарілі моделі GPT-4o / GPT-4.1.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — увійдіть через `az login` перед запуском будь-якого зразка
- **Python 3.12 або новіше**

Будь ласка, переконайтеся, що у вас є доступ до цих сервісів перед початком.

> **💰 Витрати та очищення.** Практичні уроки створюють реальні ресурси Azure — проєкт Microsoft Foundry,
> розгортання моделі, векторне сховище та (в уроках 4–6) розміщених агентів і набори інструментів.
> Вони можуть спричиняти витрати, поки існують. Коли ви закінчите урок або курс — видаліть
> ресурси, які більше не потрібні. Найпростіший спосіб — розмістити все в окремій групі ресурсів
> та видалити всю групу, коли закінчите:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Також можна видаляти окремих агентів, векторні сховища та набори інструментів через портал Foundry.

> **Примітка щодо моделей.** Цей курс подає всі моделі через **Microsoft Foundry**. Він **не**
> використовує *GitHub Models*, які будуть припинені **30 липня 2026 року** — Microsoft Foundry є
> офіційним шляхом міграції. Якщо у вас є старий код, який викликає GitHub Models, вкажіть йому модель
> розгортання Foundry замість цього.

Незабаром з’являться додаткові варіанти розміщення моделей і сервісів.

## 🗃️ Курси

| **Урок**         | **Опис**                                                                                  |
|--------------------|--------------------------------------------------------------------------------------------------|
| [Agent Design](./lesson-1-agent-design/README.md)       | Вступ до нашого сценарію використання агента "Введення розробника" та як проєктувати ефективні агенти  |
| [Agent Development](./lesson-2-agent-development/README.md)  | Використовуючи Microsoft Agent Framework (MAF), створіть набір спеціалізованих агентів для допомоги новим розробникам.       |
| [Agent Evaluations](./lesson-3-agent-evals/README.md)  | За допомогою Microsoft Foundry дізнайтеся, наскільки добре працюють наші AI агенти і як їх покращити. |
| [Agent Deployment](./lesson-4-agentdeployment/README.md)   | Використовуючи розміщених агентів Microsoft Foundry і OpenAI ChatKit, подивіться, як розгорнути AI агента в продукцію.       |
| [Production Hosted Agents](./lesson-5-hosted-agents-production/README.md)   | Переведіть розміщеного агента до підприємницької продукції: розміщені агенти проти Capability Hosts, використовуйте власне сховище, пам’ять та управління.       |
| [Microsoft Toolbox](./lesson-6-toolbox/README.md)   | Визначте інструменти раз і централізовано керуйте ними: створіть набір інструментів, використовуйте його через один MCP кінцевий пункт та безпечно керуйте версіями.       |
| [Multi-Agent & A2A](./lesson-7-multi-agent-a2a/README.md)   | Складіть агентів як мережні служби: відкрийте агента через відкритий протокол Agent-to-Agent (A2A) та використовуйте віддаленого агента як рівного.       |
