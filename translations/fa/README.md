> **ترجیح می‌دهید به صورت محلی کلون کنید؟**
>
> این مخزن بیش از ۵۰ ترجمه زبان دارد که حجم دانلود را به طور قابل توجهی افزایش می‌دهد. برای کلون بدون ترجمه‌ها، از sparse checkout استفاده کنید:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production.git
> cd Building-AI-Agents-From-Zero-To-Production
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (ویندوز):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production.git
> cd Building-AI-Agents-From-Zero-To-Production
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> این به شما همه چیز لازم برای تکمیل دوره با دانلود بسیار سریع‌تر را می‌دهد.

## 🌱 شروع به کار

این دوره درس‌هایی درباره اصول ساخت و استقرار عوامل هوش مصنوعی دارد.

هر درس بر درس قبلی بنا شده است، پس توصیه می‌کنیم از ابتدا شروع کرده و تا پایان پیش بروید.

اگر می‌خواهید بیشتر درباره موضوعات عوامل هوش مصنوعی کاوش کنید، می‌توانید دوره [AI Agents For Beginners Course](https://aka.ms/ai-agents-beginners) را بررسی کنید.

### ملاقات با دیگر یادگیرندگان، پاسخ به سوالات شما

اگر به مشکلی خوردید یا سوالی درباره ساخت عوامل هوش مصنوعی داشتید، به کانال دیسکورد اختصاصی ما در [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6) بپیوندید.

### موارد مورد نیاز شما


هر درس نمونه کد مخصوص به خود را دارد که می‌توانید به صورت محلی اجرا کنید. می‌توانید این مخزن را [فورک کنید](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) تا نسخه خودتان را بسازید.

این دوره در حال حاضر از موارد زیر استفاده می‌کند:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — پروژه‌ای با مدلی از سری **GPT-5** مستقر (مثلاً `gpt-5.1`). لطفاً از مدل‌های بازنشسته GPT-4o / GPT-4.1 استفاده نکنید.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — قبل از اجرای هر نمونه با `az login` وارد شوید
- **Python 3.12 یا جدیدتر**

لطفاً قبل از شروع مطمئن شوید به این سرویس‌ها دسترسی دارید.

> **💰 هزینه و پاکسازی.** درس‌های عملی منابع واقعی Azure ایجاد می‌کنند — پروژه Microsoft Foundry،
> استقرار مدل، فروشگاه برداری، و (در دروس ۴–۶) عوامل میزبانی شده و جعبه‌ابزارها.
> این‌ها می‌توانند تا زمانی که وجود دارند هزینه داشته باشند. وقتی درس یا کل دوره را تمام کردید،
> منابعی که دیگر نیاز ندارید را حذف کنید. ساده‌ترین روش این است که همه چیز را در یک گروه منبع اختصاصی قرار دهید
> و وقتی تمام شد آن گروه را پاک کنید:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> همچنین می‌توانید عوامل، فروشگاه‌های برداری، و جعبه‌ابزارهای جداگانه را از پرتال Foundry حذف کنید.

> **توجه درباره مدل‌ها.** این دوره همه مدل‌ها را از طریق **Microsoft Foundry** ارائه می‌دهد. این دوره از *GitHub Models* استفاده نمی‌کند، که در
> تاریخ **۳۰ ژوئیه ۲۰۲۶** بازنشسته می‌شود — Microsoft Foundry مسیر رسمی مهاجرت است. اگر کد قدیمی دارید که از GitHub Models استفاده می‌کند،
> آن را به جای آن به استقرار یک مدل Foundry اشاره دهید.

این پروژه کد رفتار منبع باز مایکروسافت را اتخاذ کرده است [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
