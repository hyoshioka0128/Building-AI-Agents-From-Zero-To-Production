## 🌱 Pour Commencer

Ce cours comprend des leçons couvrant les fondamentaux de la création et du déploiement d'Agents IA.

Chaque leçon s'appuie sur la précédente, nous recommandons donc de commencer dès le début et de progresser jusqu'à la fin.

Si vous souhaitez explorer davantage les sujets liés aux Agents IA, vous pouvez consulter le [Cours Agents IA pour Débutants](https://aka.ms/ai-agents-beginners).

### Rencontrez d'autres apprenants, obtenez des réponses à vos questions

Si vous bloquez ou avez des questions sur la construction d'Agents IA, rejoignez notre chaîne Discord dédiée dans le [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### Ce dont vous avez besoin

Chaque leçon dispose de son propre exemple de code que vous pouvez exécuter localement. Vous pouvez [forker ce repo](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) pour créer votre propre copie.

Ce cours utilise actuellement les éléments suivants :

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — un projet avec un modèle de la série **GPT-5** déployé (par exemple `gpt-5.1`). Ne **pas** utiliser les modèles retraités GPT-4o / GPT-4.1.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — connectez-vous avec `az login` avant d'exécuter un exemple
- **Python 3.12 ou ultérieur**

Veuillez vous assurer d'avoir accès à ces services avant de commencer.

> **💰 Coût & nettoyage.** Les leçons pratiques créent de vraies ressources Azure — un projet Microsoft Foundry,
> un déploiement de modèle, un magasin vectoriel, et (dans les Leçons 4–6) des agents et boîtes à outils hébergés.
> Ceux-ci peuvent engendrer des coûts tant qu'ils existent. Lorsque vous terminez une leçon — ou le cours — supprimez les
> ressources dont vous n'avez plus besoin. La méthode la plus simple est de tout mettre dans un groupe de ressources dédié
> et de supprimer tout le groupe lorsque vous avez fini :
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Vous pouvez également supprimer les agents, magasins vectoriels et boîtes à outils individuellement depuis le portail Foundry.

> **Note sur les modèles.** Ce cours sert tous les modèles via **Microsoft Foundry**. Il n’utilise **pas**
> *GitHub Models*, qui sera retiré le **30 juillet 2026** — Microsoft Foundry est
> la voie officielle de migration. Si vous avez du code ancien utilisant GitHub Models, pointez-le vers un déploiement
> de modèle Foundry à la place.

D'autres options autour de l'hébergement de modèles et des services seront bientôt disponibles.

## 🗃️ Leçons

| **Leçon**         | **Description**                                                                                  |
|--------------------|--------------------------------------------------------------------------------------------------|
| [Conception d'Agent](./lesson-1-agent-design/README.md)       | Introduction à notre cas d’utilisation "Intégration Développeur" et comment concevoir des agents efficaces  |
| [Développement d'Agent](./lesson-2-agent-development/README.md)  | Utilisation du Microsoft Agent Framework (MAF), construire un ensemble d’agents spécialisés pour aider les nouveaux développeurs à s’intégrer.       |
| [Évaluations d'Agent](./lesson-3-agent-evals/README.md)  | Utilisation de Microsoft Foundry pour évaluer la performance de nos Agents IA et comment les améliorer. |
| [Déploiement d'Agent](./lesson-4-agentdeployment/README.md)   | Avec Microsoft Foundry hébergement d’agents et OpenAI ChatKit, voir comment déployer un Agent IA en production.       |
| [Agents Hébergés en Production](./lesson-5-hosted-agents-production/README.md)   | Mettez un agent hébergé en production d'entreprise : Agents Hébergés vs Hôtes de Capacité, apportez votre propre stockage, mémoire et gouvernance.       |
| [Boîte à Outils Microsoft](./lesson-6-toolbox/README.md)   | Définissez les outils une seule fois et gérez-les centralement : construisez une boîte à outils, consommez-la depuis un agent via un seul point d’extrémité MCP, et versionnez les outils en toute sécurité.       |
| [Multi-Agent & A2A](./lesson-7-multi-agent-a2a/README.md)   | Composez des agents comme services en réseau : exposez un agent via le protocole ouvert Agent-to-Agent (A2A) et consommez un agent distant comme un pair.       |
