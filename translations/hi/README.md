## 🌱 शुरुआत करना

इस कोर्स में AI एजेंट बनाने और तैनात करने के मूलभूत पाठ शामिल हैं।

प्रत्येक पाठ पिछली कड़ी पर आधारित है, इसलिए हम अनुशंसा करते हैं कि आप शुरुआत से शुरू करें और अंत तक काम करें।

यदि आप AI एजेंट विषयों के बारे में और जानना चाहते हैं, तो आप [AI एजेंट्स फॉर बिगिनर्स कोर्स](https://aka.ms/ai-agents-beginners) देख सकते हैं।

### अन्य शिक्षार्थियों से मिलें, अपने सवालों के जवाब पाएं

यदि आप फंसे हैं या AI एजेंट बनाने के संबंध में कोई प्रश्न है, तो हमारे समर्पित Discord चैनल में शामिल हों [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6)।

### आपको क्या चाहिए


प्रत्येक पाठ का अपना कोड नमूना होता है जिसे आप स्थानीय रूप से चला सकते हैं। आप अपनी खुद की कॉपी बनाने के लिए [इस रिपॉ को फोर्क कर सकते हैं](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork)।

यह कोर्स वर्तमान में निम्नलिखित उपयोग करता है:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — एक प्रोजेक्ट जिसमें **GPT-5 सीरीज** मॉडल तैनात है (उदाहरण के लिए `gpt-5.1`)। कृपया खोए हुए GPT-4o / GPT-4.1 मॉडलों का उपयोग **नहीं** करें।
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — किसी भी नमूना को चलाने से पहले `az login` के साथ साइन इन करें
- **Python 3.12 या बाद का संस्करण**

कृपया सुनिश्चित करें कि आपके पास शुरू करने से पहले इन सेवाओं तक पहुंच है।

> **💰 लागत और सफाई।** हैंड्स-ऑन पाठ वास्तविक Azure संसाधन बनाते हैं — एक Microsoft Foundry
> प्रोजेक्ट, एक मॉडल तैनाती, एक वेक्टर स्टोर, और (पाठ 4–6 में) होस्ट किए गए एजेंट और टूलबॉक्स।
> ये होते हुए लागत उत्पन्न कर सकते हैं। जब आप एक पाठ — या पूरा कोर्स — समाप्त कर लें, तो
> उन संसाधनों को हटा दें जिनकी आपको अब आवश्यकता नहीं है। सबसे सरल तरीका यह है कि सब कुछ एक समर्पित संसाधन
> समूह में रखें और जब आप समाप्त कर लें तो पूरे समूह को हटा दें:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> आप Foundry पोर्टल से व्यक्तिगत एजेंट, वेक्टर स्टोर, और टूलबॉक्स भी हटा सकते हैं।

> **मॉडल पर नोट।** यह कोर्स सभी मॉडलों को **Microsoft Foundry** के माध्यम से सेवा देता है। यह **GitHub Models** का उपयोग **नहीं** करता है, जिसे **30 जुलाई, 2026** को रिटायर किया जा रहा है — Microsoft Foundry आधिकारिक माइग्रेशन मार्ग है। यदि आपके पास पुराना कोड है जो GitHub Models को कॉल करता है, तो इसे Foundry मॉडल तैनाती की ओर निर्देशित करें।




मॉडल होस्टिंग और सेवाओं के आसपास अधिक विकल्प जल्द ही आएंगे।
