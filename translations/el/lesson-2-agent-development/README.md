# Μάθημα 2 Ανάπτυξη Πρακτόρων

Καλώς ήρθατε στο δεύτερο μάθημα του "Μαθήματος Δημιουργίας Πρακτόρων AI από το Μηδέν έως την Παραγωγή"!

Σε αυτό το μάθημα θα καλύψουμε:

- Τα Εργαλεία για τη Δημιουργία των Πρακτόρων AI μας
  
- Οδηγίες Ρυθμίσεων για τους Πόρους Ανάπτυξής μας

- Καλύτερες Πρακτικές Ανάπτυξης Πρακτόρων AI
  
- Περιήγηση Κώδικα για τη Δημιουργία των Πρακτόρων AI μας
  
Ας ξεκινήσουμε κοιτάζοντας τα εργαλεία που θα χρησιμοποιήσουμε για να δημιουργήσουμε τους Πράκτορες AI μας.

## Εργαλεία και Οδηγίες Ρύθμισης

### Microsoft Foundry

Για πρόσβαση σε Μεγάλα Μοντέλα Γλώσσας (LLMs) θα χρησιμοποιήσουμε το [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry). Υπάρχουν κόστη που σχετίζονται με τη χρήση του Foundry, οπότε βεβαιωθείτε ότι ακολουθείτε τις οδηγίες για τη ρύθμιση λογαριασμού αν δεν έχετε ήδη πρόσβαση.

### Μοντέλα OpenAI

Τα δείγματα κώδικα πρακτόρων σε αυτό το μάθημα είναι ρυθμισμένα να χρησιμοποιούν μοντέλα OpenAI μέσω του [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry).

Χρησιμοποιήστε αυτόν τον οδηγό για να μάθετε πώς να αναπτύξετε ένα μοντέλο χρησιμοποιώντας το Foundry: [Deploy Microsoft Foundry Models in the Foundry portal](https://learn.microsoft.com/azure/ai-foundry/foundry-models/how-to/deploy-foundry-models?view=foundry-classic)

Επιλέξτε ένα μοντέλο της σειράς GPT-5 (για παράδειγμα `gpt-5.1`) για αυτό το μάθημα. Αποφύγετε μοντέλα που έχουν αποσυρθεί όπως GPT-4o και GPT-4.1, τα οποία φτάνουν στο τέλος ζωής το 2026.

### Microsoft Agent Framework

Όπως αναφέρθηκε προηγουμένως, θα χρησιμοποιήσουμε το [Microsoft Agent Framework](https://github.com/microsoft/agent-framework) για να δημιουργήσουμε και να οργανώσουμε τους Πράκτορες AI μας.

Θα χρειαστείτε **Python 3.12 ή μεταγενέστερη έκδοση**. Για να εγκαταστήσετε το Microsoft Agent Framework και άλλα απαιτούμενα πακέτα, εκτελέστε την ακόλουθη εντολή ενώ βρίσκεστε στον ριζικό φάκελο αυτού του έργου:

```bash
pip install -r requirements.txt
```

### Πιστοποίηση με το Azure

Οι πράκτορες πιστοποιούνται στο Microsoft Foundry χρησιμοποιώντας τα διαπιστευτήρια Azure CLI σας
(`AzureCliCredential`), οπότε πρέπει να συνδεθείτε πριν εκτελέσετε οποιοδήποτε δείγμα:

```bash
az login
# Εάν έχετε περισσότερες από μία συνδρομές, επιλέξτε αυτή με το έργο Foundry σας:
az account set --subscription "<your-subscription-id>"
```

Βεβαιωθείτε ότι ο λογαριασμός σας έχει τον ρόλο **Azure AI User** (ή ισοδύναμο) στο έργο Foundry
ώστε να μπορεί να καλεί τα APIs μοντέλων και πρακτόρων.

### Ρύθμιση μεταβλητών .env

Για να εκτελέσετε τα παραδείγματα κώδικα σε αυτό το μάθημα, θα χρειαστεί να δημιουργήσετε ένα αρχείο `.env` στον ριζικό φάκελο αυτού του έργου. 

Για να γίνει πιο εύκολο, μπορείτε να αντιγράψετε το παρεχόμενο αρχείο `.env.example`:

```bash
cp .env.example .env
``` 

Στη συνέχεια συμπληρώστε τις δύο μεταβλητές που διαβάζουν οι πράκτορες (οι `FoundryChatClient` τις παίρνουν
αυτόματα):

| Μεταβλητή | Τι είναι | Πού να τη βρείτε |
|----------|------------|------------------|
| `FOUNDRY_PROJECT_ENDPOINT` | Το endpoint του έργου Foundry σας, που τελειώνει σε `/api/projects/<project>` | Πύλη Foundry → το έργο σας → **Σύνοψη** → *Endpoints* |
| `FOUNDRY_MODEL` | Το όνομα ανάπτυξης μοντέλου που χρησιμοποιούν οι πράκτορές σας (για παράδειγμα `gpt-5.1`) | Πύλη Foundry → **Μοντέλα + endpoints** |

### Δημιουργήστε το vector store των υπαλλήλων

Ένα δείγμα — ο **Πράκτορας Αναζήτησης Υπαλλήλων** — ψάχνει σε έναν κατάλογο υπαλλήλων που βρίσκεται σε
ένα Microsoft Foundry **vector store**. Δημιουργήστε το μία φορά και αντιγράψτε το ID που θα εμφανίσει στο `.env`
ως `VECTOR_STORE_ID` (εκτελέστε από τη ρίζα του repository ώστε να πιάσει το `.env` σας):

```bash
python lesson-2-agent-development/setup_vector_store.py
```

### Εκτέλεση ενός δείγματος

Κάθε πράκτορας τρέχει το δικό του τοπικό DevUI. Για παράδειγμα:

```bash
python lesson-2-agent-development/employee-search-agent.py
```

Στη συνέχεια, ανοίξτε το εκτυπωμένο URL `http://localhost:<port>` στον browser σας για να συνομιλήσετε με τον πράκτορα.

## Οι πράκτορες αυτού του μαθήματος

Κάθε δείγμα είναι ένας αυτόνομος πράκτορας που έχει δημιουργηθεί με το Microsoft Agent Framework. Μαζί 
υλοποιούν τα σενάρια που σχεδιάσατε στο [Μάθημα 1](../lesson-1-agent-design/README.md):

| Δείγμα | Σενάριο Μαθήματος 1 | Χρησιμοποιούμενο Εργαλείο | Θύρα |
|--------|-------------------|-----------|------|
| `employee-search-agent.py` | Σενάριο 1 — Αναζήτηση Υπαλλήλου | Αναζήτηση αρχείων με Foundry πάνω σε vector store | 8090 |
| `task-recommendation-agent.py` | Σενάριο 2 — Πρόταση Εργασιών | Διακομιστής **GitHub MCP** (φιλοξενούμενο εργαλείο MCP) | 8095 |
| `azure-learning-agent.py` | Σενάριο 3 — Βοηθός Κώδικα (έρευνα) | Διακομιστής **Microsoft Learn MCP** (φιλοξενούμενο εργαλείο MCP) | 8092 |
| `coding-agent.py` | Σενάριο 3 — Βοηθός Κώδικα (κώδικας) | **Code Interpreter** | 8093 |
| `learning-recommendation-agent.py` | Υποστηρικτικός πράκτορας | Learn MCP + λογική | 8091 |
| `agent-orchestration.py` | Συνδέει τα σενάρια μαζί | Πολλαπλοί πράκτορες για **handoff** ορχήστρα | 8094 |

> **Σημείωση για τον Πράκτορα Πρότασης Εργασιών.** Το `task-recommendation-agent.py` χρειάζεται
> `GITHUB_PERSONAL_ACCESS_TOKEN` στο `.env` σας (δημιουργήστε ένα στο
> <https://github.com/settings/personal-access-tokens/new>). Διαβάζει τη πρόσφατη
> δραστηριότητα GitHub ενός προγραμματιστή και προτείνει 1–3 ανοιχτά ζητήματα που ταιριάζουν — ακριβώς το σενάριο 2.
> Αυτό είναι το μόνο δείγμα που καλεί το GitHub· τα υπόλοιπα χρειάζονται μόνο το έργο Foundry σας.
