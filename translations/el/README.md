## 🌱 Ξεκινώντας

Αυτό το μάθημα περιλαμβάνει μαθήματα που καλύπτουν τα βασικά της δημιουργίας και ανάπτυξης Πρακτόρων AI.

Κάθε μάθημα χτίζει πάνω στο προηγούμενο, οπότε συνιστούμε να ξεκινήσετε από την αρχή και να προχωρήσετε μέχρι το τέλος.

Αν θέλετε να εξερευνήσετε περισσότερα για τα θέματα των Πρακτόρων AI, μπορείτε να δείτε το [Μάθημα Πρακτόρων AI για Αρχάριους](https://aka.ms/ai-agents-beginners).

### Γνωρίστε Άλλους Μαθητές, Λάβετε Απαντήσεις στις Ερωτήσεις σας

Αν κολλήσετε ή έχετε ερωτήσεις σχετικά με τη δημιουργία Πρακτόρων AI, συμμετάσχετε στο ειδικό μας κανάλι Discord στο [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### Τι Χρειάζεστε

Κάθε μάθημα έχει το δικό του δείγμα κώδικα που μπορείτε να εκτελέσετε τοπικά. Μπορείτε να [κάνετε fork αυτό το αποθετήριο](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) για να δημιουργήσετε το δικό σας αντίγραφο.

Αυτό το μάθημα αυτή τη στιγμή χρησιμοποιεί τα εξής:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — ένα έργο με αναπτυγμένο μοντέλο **σειράς GPT-5** (για παράδειγμα `gpt-5.1`). Μην χρησιμοποιείτε τα αποσυρμένα μοντέλα GPT-4o / GPT-4.1.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — συνδεθείτε με `az login` πριν τρέξετε οποιοδήποτε δείγμα
- **Python 3.12 ή νεότερο**

Βεβαιωθείτε ότι έχετε πρόσβαση σε αυτές τις υπηρεσίες πριν ξεκινήσετε.

> **💰 Κόστος & καθαρισμός.** Τα πρακτικά μαθήματα δημιουργούν πραγματικούς πόρους Azure — ένα έργο Microsoft Foundry,
> αναπτύξεις μοντέλων, αποθήκη διανυσμάτων και (στα Μαθήματα 4–6) φιλοξενούμενους πράκτορες και εργαλειοθήκες.
> Αυτοί μπορούν να επιφέρουν κόστος όσο υπάρχουν. Όταν ολοκληρώσετε ένα μάθημα — ή το μάθημα — διαγράψτε
> τους πόρους που δεν χρειάζεστε πλέον. Η απλούστερη μέθοδος είναι να βάλετε τα πάντα σε μια αφιερωμένη ομάδα πόρων
> και να διαγράψετε ολόκληρη την ομάδα όταν τελειώσετε:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Μπορείτε επίσης να διαγράψετε μεμονωμένους πράκτορες, αποθήκες διανυσμάτων και εργαλειοθήκες από την πύλη Foundry.

> **Σημείωση για τα μοντέλα.** Αυτό το μάθημα σερβίρει όλα τα μοντέλα μέσω **Microsoft Foundry**. Δεν
> χρησιμοποιεί *GitHub Models*, τα οποία αποσύρονται στις **30 Ιουλίου 2026** — το Microsoft Foundry είναι
> η επίσημη διαδρομή μετανάστευσης. Αν έχετε παλαιότερο κώδικα που καλεί GitHub Models, δείξτε τον σε μια
> ανάπτυξη μοντέλου Foundry αντίστοιχα.

Περισσότερες επιλογές για φιλοξενία μοντέλων και υπηρεσίες έρχονται σύντομα.
