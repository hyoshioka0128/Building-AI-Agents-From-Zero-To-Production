## 🌱 Rozpoczęcie

Ten kurs zawiera lekcje dotyczące podstaw tworzenia i wdrażania agentów AI.

Każda lekcja opiera się na poprzedniej, więc zalecamy rozpoczęcie od początku i przechodzenie kolejno do końca.

Jeśli chcesz zgłębić więcej tematów dotyczących agentów AI, możesz sprawdzić [Kurs dla początkujących Agentów AI](https://aka.ms/ai-agents-beginners).

### Spotkaj innych uczniów i uzyskaj odpowiedzi na pytania

Jeśli utkniesz lub masz pytania dotyczące tworzenia agentów AI, dołącz do naszego dedykowanego Kanału Discord w [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### Co jest potrzebne

Każda lekcja zawiera własny przykład kodu, który możesz uruchomić lokalnie. Możesz [sforkować to repozytorium](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork), aby utworzyć własną kopię.

Obecnie kurs korzysta z następujących narzędzi:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — projekt z modelem z serii **GPT-5** (np. `gpt-5.1`). Nie używaj modeli wycofanych GPT-4o / GPT-4.1.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — zaloguj się poleceniem `az login` przed uruchomieniem jakiegokolwiek przykładu
- **Python 3.12 lub nowszy**

Upewnij się, że masz dostęp do tych usług przed rozpoczęciem.

> **💰 Koszt i sprzątanie.** Lekcje praktyczne tworzą rzeczywiste zasoby Azure — projekt Microsoft Foundry,
> wdrożenie modelu, magazyn wektorowy oraz (w lekcjach 4–6) hostowanych agentów i zestawy narzędzi.
> Te zasoby mogą generować koszty tak długo, jak istnieją. Po zakończeniu lekcji — lub kursu —
> usuń zasoby, których nie potrzebujesz. Najprościej jest umieścić wszystko w dedykowanej grupie zasobów
> i usunąć całą grupę po zakończeniu:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Możesz też usuwać pojedynczych agentów, magazyny wektorów i zestawy narzędzi z portalu Foundry.

> **Uwaga na modele.** Ten kurs korzysta ze wszystkich modeli za pośrednictwem **Microsoft Foundry**. Nie używa on *GitHub Models*, które zostaną wycofane 30 lipca 2026 r. — Microsoft Foundry to
> oficjalna ścieżka migracji. Jeśli masz starszy kod korzystający z GitHub Models, skieruj go na wdrożenie modelu Foundry.



Wkrótce pojawią się kolejne opcje dotyczące hostowania modeli i usług.

| [Tworzenie agenta](./lesson-2-agent-development/README.md)  | Za pomocą Microsoft Agent Framework (MAF) zbuduj zestaw wyspecjalizowanych agentów wspierających nowych deweloperów.       |
