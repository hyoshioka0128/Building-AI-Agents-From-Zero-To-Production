## 🌱 Iniziare

Questo corso ha lezioni che coprono le basi della costruzione e del deployment di Agenti AI.

Ogni lezione si basa su quella precedente, quindi consigliamo di iniziare dall'inizio e procedere fino alla fine.

Se vuoi esplorare di più sugli argomenti degli Agenti AI, puoi dare un'occhiata al [Corso per Principianti sugli Agenti AI](https://aka.ms/ai-agents-beginners).

### Incontra Altri Studenti, Fatti Rispondere alle Tue Domande

Se rimani bloccato o hai domande sulla costruzione di Agenti AI, unisciti al nostro canale Discord dedicato nel [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### Cosa Ti Serve


Ogni Lezione ha un proprio esempio di codice che puoi eseguire localmente. Puoi [forkare questo repo](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) per creare la tua copia.

Questo corso attualmente utilizza i seguenti:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — un progetto con un modello della serie **GPT-5** distribuito (per esempio `gpt-5.1`). Non utilizzare i modelli GPT-4o / GPT-4.1 ritirati.
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — accedi con `az login` prima di eseguire qualsiasi esempio
- **Python 3.12 o successivo**

Assicurati di avere accesso a questi servizi prima di iniziare.

> **💰 Costi e pulizia.** Le lezioni pratiche creano risorse Azure reali — un progetto Microsoft Foundry,
> una distribuzione del modello, un archivio vettoriale e (nelle Lezioni 4–6) agenti e toolbox ospitati.
> Questi possono generare costi finché esistono. Quando finisci una lezione — o il corso — elimina le
> risorse che non ti servono più. L'approccio più semplice è mettere tutto in un gruppo di risorse dedicato
> ed eliminare l’intero gruppo quando hai finito:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> Puoi anche eliminare singoli agenti, archivi vettoriali e toolbox dal portale Foundry.

> **Nota sui modelli.** Questo corso serve tutti i modelli tramite **Microsoft Foundry**. Non utilizza
> *GitHub Models*, che sarà ritirato il **30 luglio 2026** — Microsoft Foundry è il
> percorso ufficiale di migrazione. Se hai codice più vecchio che chiama GitHub Models, puntalo invece
> su una distribuzione di modello Foundry.

Presto saranno disponibili altre opzioni per l’hosting di modelli e servizi.

## 🗃️ Lezioni

| **Lezione**         | **Descrizione**                                                                                  |
|--------------------|--------------------------------------------------------------------------------------------------|
| [Agent Design](./lesson-1-agent-design/README.md)       | Un’introduzione al caso d’uso "Developer Onboarding" per agenti e come progettare agenti efficaci  |
| [Agent Development](./lesson-2-agent-development/README.md)  | Usando Microsoft Agent Framework (MAF), costruisci una serie di agenti specializzati per aiutare i nuovi sviluppatori nell’onboarding.       |
| [Agent Evaluations](./lesson-3-agent-evals/README.md)  | Usando Microsoft Foundry, scopri come stanno andando i nostri Agenti AI e come migliorarli. |
| [Agent Deployment](./lesson-4-agentdeployment/README.md)   | Usando agenti ospitati Microsoft Foundry e OpenAI ChatKit, scopri come distribuire un Agente AI in produzione.       |
| [Production Hosted Agents](./lesson-5-hosted-agents-production/README.md)   | Porta un agente ospitato in produzione aziendale: Agenti Ospitati contro Host di Capacità, storage, memoria e governance portati dall’utente.       |
| [Microsoft Toolbox](./lesson-6-toolbox/README.md)   | Definisci strumenti una volta e governali centralmente: costruisci una toolbox, usala da un agente tramite un singolo endpoint MCP, e gestisci in sicurezza le versioni degli strumenti.       |
| [Multi-Agent & A2A](./lesson-7-multi-agent-a2a/README.md)   | Componi agenti come servizi in rete: esponi un agente tramite il protocollo aperto Agent-to-Agent (A2A) e consuma un agente remoto come pari.       |
