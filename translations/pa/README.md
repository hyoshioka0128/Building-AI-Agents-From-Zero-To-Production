ਜੇ ਤੁਸੀਂ AI ਏਜੰਟ ਵਿਸ਼ਿਆਂ ਬਾਰੇ ਹੋਰ ਪਤਾ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਤੁਸੀਂ [AI ਏਜੰਟਾਂ ਲਈ ਸ਼ੁਰੂਆਤੀ ਕੋਰਸ](https://aka.ms/ai-agents-beginners) ਨੂੰ ਦੇਖ ਸਕਦੇ ਹੋ।

### ਤੁਹਾਨੂੰ ਕੀ ਚਾਹੀਦਾ ਹੈ

ਹਰੇਕ ਲੈਸਨ ਦੇ ਕੋਲ ਆਪਣਾ ਕੋਡ ਸੈਂਪਲ ਹੁੰਦਾ ਹੈ ਜੋ ਤੁਸੀਂ ਲੋਕਲ ਤੌਰ 'ਤੇ ਚਲਾ ਸਕਦੇ ਹੋ। ਤੁਸੀਂ ਆਪਣੀ ਕਾਪੀ ਬਣਾਉਣ ਲਈ [ਇਸ ਰੇਪੋ ਨੂੰ ਫੋਰਕ ਕਰੋ](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork)।

ਇਹ ਕੋਰਸ ਵਰਤਮਾਨ ਵਿੱਚ ਹੇਠ ਲਿਖੀਆਂ ਚੀਜ਼ਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — ਇੱਕ ਪ੍ਰੋਜੈਕਟ ਜਿਸ ਵਿੱਚ ਤੈਨਾਤ ਕੀਤਾ ਗਿਆ **GPT-5 ਸੀਰੀਜ਼** ਮਾਡਲ ਹੈ (ਉਦਾਹਰਨ ਲਈ `gpt-5.1`). ਕਿਰਪਾ ਕਰਕੇ ਰਿਟਾਇਰਡ GPT-4o / GPT-4.1 ਮਾਡਲਾਂ ਦੀ ਵਰਤੋਂ ਨਾ ਕਰੋ।
- [Azure OpenAI Service](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [Azure CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — ਕਿਸੇ ਵੀ ਸੈਂਪਲ ਨੂੰ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ `az login` ਨਾਲ ਸਾਈਨ ਇਨ ਕਰੋ
- **Python 3.12 ਜਾਂ ਉਸ ਤੋਂ ਨਵਾਂ**

ਕਿਰਪਾ ਕਰਕੇ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਇਹਨਾਂ ਸੇਵਾਵਾਂ ਤੱਕ ਤੁਹਾਡੀ ਪਹੁੰਚ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ।

> **💰 ਲਾਗਤ ਅਤੇ ਸਫਾਈ।** ਹੱਥ-ਅਨੁਭਵੀ ਪਾਠ ਅਸਲ Azure ਸਰੋਤ ਬਣਾਉਂਦੇ ਹਨ — ਇੱਕ Microsoft Foundry
> ਪ੍ਰੋਜੈਕਟ, ਇੱਕ ਮਾਡਲ ਡਿਪਲੋਇਮੈਂਟ, ਇੱਕ ਵੈਕਟਰ ਸਟੋਰ, ਅਤੇ (ਪਾਠ 4–6 ਵਿੱਚ) ਹੋਸਟ ਕੀਤੇ ਏਜੰਟ ਅਤੇ ਟੂਲਬਾਕਸ।
> ਇਹਨਾਂ ਦੇ ਮੌਜੂਦ ਹੋਣ ਦੌਰਾਨ ਖਰਚ ਆ ਸਕਦੇ ਹਨ। ਜਦੋਂ ਤੁਸੀਂ ਇੱਕ ਪਾਠ — ਜਾਂ ਕੋਰਸ — ਖਤਮ ਕਰ ਲਓ, ਤਾਂ ਉਹ
> ਸਰੋਤ ਜਿਹਨਾਂ ਦੀ ਤੁਹਾਨੂੰ ਲੋੜ ਨਹੀਂ, ਮਿਟਾ ਦਿਓ। ਸਭ ਤੋਂ ਸਧਾਰਨ ਤਰੀਕਾ ਇਹ ਹੈ ਕਿ ਸਭ ਕੁਝ ਇੱਕ ਸਮਰਪਿਤ ਰਿਸੋਰਸ
> ਸਮੂਹ ਵਿੱਚ ਰੱਖੋ ਅਤੇ ਜਦੋਂ ਤੁਸੀਂ ਖਤਮ ਕਰ ਲਵੋ ਤਾਂ ਪੂਰੇ ਗਰੁੱਪ ਨੂੰ ਹਟਾ ਦਿਓ:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> ਤੁਸੀਂ Foundry ਪੋਰਟਲ ਤੋਂ ਵੱਖ-ਵੱਖ ਏਜੰਟ, ਵੈਕਟਰ ਸਟੋਰ, ਅਤੇ ਟੂਲਬਾਕਸ ਵੀ ਹਟਾ ਸਕਦੇ ਹੋ।
