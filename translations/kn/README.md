## 🌱 ಪ್ರಾರಂಭಿಸುವುದು

ಈ ಕೋರ್ಸ್ AI ಏಜೆಂಟ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವ ಮತ್ತು ನಿಯೋಜಿಸುವ ಮೂಲಭೂತಗಳನ್ನು ಒಳಗೊಂಡ ಪಾಠಗಳನ್ನು ಹೊಂದಿದೆ.

ಪ್ರತಿ ಪಾಠವು ಮೊದಲು ಯಿದ್ದ ಪಾಠದ ಮೇಲೆ ಕಟ್ಟಿಕೊಂಡಿರುತ್ತದೆ, ಆದದರಿಂದ ನಾವು ಪ್ರಾರಂಭದಿಂದಲೇ ಶುರುಮಾಡಿ ಕೊನೆಯವರೆಗೆ ತಲುಪುವುದನ್ನು ಶಿಫಾರಸು ಮಾಡುತ್ತೇವೆ.

ನೀವು AI ಏಜೆಂಟ್ ವಿಷಯಗಳನ್ನು ಇನ್ನಷ್ಟು ಅನ್ವೇಷಿಸಲು ಬಯಸಿದರೆ, ನೀವು [AI Agents For Beginners Course](https://aka.ms/ai-agents-beginners) ಅನ್ನು ಪರಿಶೀಲಿಸಬಹುದು.

### ಇತರ ಕಲಿಕಾರ್ಹರನ್ನು ಭೇಟಿ ಮಾಡಿ, ನಿಮ್ಮ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರ ಪಡೆಯಿರಿ

ನೀವು ಸಡಿಲವಾಗಿದ್ದರೆ ಅಥವಾ AI ಏಜೆಂಟ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವ ಬಗ್ಗೆ ಯಾವುದೇ ಪ್ರಶ್ನೆಗಳಿದ್ದರೆ, ದಯವಿಟ್ಟು ನಮ್ಮ ವಿಶಿಷ್ಟ Discord ಚಾನೆಲ್‌ನಲ್ಲಿ ಸೇರಿಕೊಳ್ಳಿ [Microsoft Foundry Discord](https://discord.gg/Kuaw3ktsu6).

### ನಿಮಗೆ ಬೇಕಾಗಿರುವುದು


ಪ್ರತಿ ಪಾಠಕ್ಕೂ ಸ್ಥಳೀಯವಾಗಿ ಚಾಲನೆ ಮಾಡಬಹುದಾದ ತನ್ನದೇ ಆದ ಕೋಡ್ ಉದಾಹರಣೆಗಳಿವೆ. ನೀವು [ಈ ರೆಪೋವನ್ನು ಫೋರ್ಕ್ ಮಾಡಬಹುದು](https://github.com/microsoft/Building-AI-Agents-From-Zero-To-Production/fork) ನಿಮ್ಮ ಸ್ವಂತ ನಕಲು ಸೃಜಿಸಲು.

ಈ ಕೋರ್ಸ್ ಪ್ರಸ್ತುತ ಕೆಳಗಿನವನ್ನು ಬಳಸುತ್ತದೆ:

- [Microsoft ಏಜೆಂಟ್ ಫ್ರೇಮ್‌ವರ್ಕ್ (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry](https://azure.microsoft.com/products/ai-foundry) — **GPT-5 ಸರಣಿಯ** ಮಾದರಿಯೊಂದನ್ನು (ಉದಾಹರಣೆಗೆ `gpt-5.1`) ಯೋಜಿಸಿದ್ದ ಒಂದು ಪ್ರಾಜೆಕ್ಟ್. ನಿವೃತ್ತಗೊಂಡ GPT-4o / GPT-4.1 ಮಾದರಿಗಳನ್ನು ಬಳಸುಬೇಡಿ.
- [ಆಝೂರ್ ಓಪನ್‌ಎಐ ಸೇವೆ](https://azure.microsoft.com/products/ai-foundry/models/openai)
- [ಆಝೂರ್ CLI](https://learn.microsoft.com/cli/azure/authenticate-azure-cli?view=azure-cli-latest) — ಯಾವುದೇ ಉದಾಹರಣೆಯನ್ನು ಚಾಲನೆಮಾಡುವ ಮೊದಲು `az login` ಮೂಲಕ ಸೈನ್ ಇನ್ ಆಗಿ
- **ಪೈಥಾನ್ 3.12 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ**

ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ನೀವು ಈ ಸೇವೆಗಳಿಗೆ ಪ್ರವೇಶ ಹೊಂದಿರುವುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.

> **💰 ವೆಚ್ಚ ಮತ್ತು ಸ್ವಚ್ಚಪಡಿಸುವಿಕೆ.** ಹ್ಯಾಂಡ್ಸ್-ಆನ್ ಪಾಠಗಳು ನಿಜವಾದ ಆಝೂರಿನ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸೃಷ್ಟಿಸುತ್ತವೆ — Microsoft Foundry
> ಪ್ರಾಜೆಕ್ಟ್, ಮಾದರಿ ನಿಯೋಜನೆ, ವೆಕ್ಟರ್ ಸ್ಟೋರ್, ಮತ್ತು (ಪಾಠಗಳು 4–6 ರಲ್ಲಿ) ಹೋಸ್ಟ್ ಮಾಡಿದ ಏಜೆಂಟ್‌ಗಳು ಮತ್ತು ಉಪಕರಣಪೆಟ್ಟಿಗೆಗಳು.
> ಅವುಗಳೂ ಇರುತ್ತಿರುವ ಸಮಯದಲ್ಲಿ ವೆಚ್ಚ ಆಗಬಹುದು. ನೀವು ಪಾಠವನ್ನು — ಅಥವಾ ಕೋರ್ಸ್ ಅನ್ನು — ಮುಗಿಸಿದಾಗ
> ನೀವು ಅಗತ್ಯವಿಲ್ಲದ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಅಳಿಸಿ. ಸಹಜ ವಿಧಾನವೆಂದರೆ ಎಲ್ಲವನ್ನೂ ಒಂದು ನಿಗದಿತ ಸಂಪನ್ಮೂಲ
> ಗುಂಪಿನಲ್ಲಿ ಇಟ್ಟು, ನೀವು ಮುಗಿಸಿದಾಗ ಆ ಸಂಪೂರ್ಣ ಗುಂಪನ್ನು ಅಳಿಸುವದು:
>
> ```bash
> az group delete --name <your-resource-group> --yes --no-wait
> ```
>
> ನೀವು Foundry ಪೋರ್ಟಲ್‌ನಿಂದ ವೈಯಕ್ತಿಕ ಏಜೆಂಟ್‌ಗಳು, ವೆಕ್ಟರ್ ಸ್ಟೋರ್‌ಗಳು ಮತ್ತು ಉಪಕರಣಪೆಟ್ಟಿಗೆಗಳನ್ನು ಕೂಡ ಅಳಿಸಬಹುದು.

> **ಮಾದರಿಗಳ ಕುರಿತಾಗಿ ಟಿಪ್ಪಣಿ.** ಈ ಕೋರ್ಸ್ ಎಲ್ಲಾ ಮಾದರಿಗಳನ್ನು **Microsoft Foundry** ಮೂಲಕ ಒದಗಿಸುತ್ತದೆ. ಇದು **GitHub ಮಾದರಿಗಳನ್ನು** ಬಳಸದಿರು
> *ಇವುಗಳನ್ನು 30 ಜುಲೈ, 2026 ರಂದು ನಿವೃತ್ತಗೊಳಿಸಲಾಗುವುದು* — Microsoft Foundry ಅಧಿಕೃತ ಹಜಾರಾತಿ ಮಾರ್ಗವಾಗಿದೆ.
> ನೀವು ಹಳೆಯ ಕೋಡ್‌ನಲ್ಲಿ GitHub ಮಾದರಿಗಳನ್ನು ಕರೆಸದಿದ್ದರೆ, ಅದನ್ನು Foundry
> ಮಾದರಿ ನಿಯೋಜನೆ ಕಡೆಗೆ ಸೂಚಿಸಿ.

ಮಾದರಿ ಹೋಸ್ಟಿಂಗ್ ಮತ್ತು ಸೇವೆಗಳ ಸುತ್ತಲೂ ಮತ್ತಷ್ಟು ಆಯ್ಕೆಗಳು ಶೀಘ್ರದಲ್ಲೇ ಬರುತ್ತಿವೆ.

## ಕೊಡುಗೆ ನೀಡುವಿಕೆ

ಈ ಯೋಜನೆ ಕೊಡುಗೆಗಳು ಮತ್ತು ಸಲಹೆಗಳನ್ನು ಸ್ವಾಗತಿಸುತ್ತದೆ. ಹೆಚ್ಚಿನ ಕೊಡುಗೆಗಳಿಗೆ ನೀವು ಒಪ್ಪಬೇಕಾಗುತ್ತದೆ
ಒಂದು ಕೊಡುಗೆದಾರ ಪರವಾನಗಿ ಒಪ್ಪಂದಕ್ಕೆ (CLA) ನೀವು ಹೊಂದಿರುವ ಹಕ್ಕುಗಳನ್ನು ಮತ್ತು ವಾಸ್ತವವಾಗಿ ಕೊಡುಗೆ ನೀಡುವ ಹಕ್ಕುಗಳನ್ನು ನಮಗೆ ನೀಡುತ್ತೀರಿ ಎಂದು ಘೋಷಿಸುವುದು. ವಿವರಗಳಿಗೆ, ಭೇಟಿ ನೀಡಿ <https://cla.opensource.microsoft.com>.


ನೀವು ಪುಲ್ ವಿನಂತಿಯನ್ನು ಸಲ್ಲಿಸಿದಾಗ, CLA ಬಾಟ್ ನಿಮ್ಮಿಗೆ CLA ನೀಡಬೇಕೆಂಬುದನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನಿರ್ಧರಿಸುತ್ತದೆ ಮತ್ತು PR ಅನ್ನು ಸೂಕ್ತವಾಗಿ ಅಲಂಕರಿಸುತ್ತದೆ (ಉದಾಹರಣೆಗೆ, ಸ್ಥಿತಿ ಪರಿಶೀಲನೆ, ಕಾಮೆಂಟ್). ಬಾಟ್ ನೀಡುವ ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ. ನಮ್ಮ CLA ಅನ್ನು ಬಳಸಿ ಎಲ್ಲಾ ರೆಪೊಗಳಲ್ಲಿ ಈ ಪ್ರಕ್ರಿಯೆಯನ್ನು ನೀವು ಒಮ್ಮೆ ಮಾತ್ರ ಮಾಡಬೇಕಾಗುತ್ತದೆ.
